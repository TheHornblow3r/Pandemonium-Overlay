**Pandemonium Overlay** is a lightweight in-game overlay for Path of Diablo that provides quick access to rune prices, runewords, corruptions, and crafting recipes — without leaving the game.

No alt-tabbing. No spreadsheets. Just fast, always-available information while you play.<br><br>

## ✨ Features

- 🔮 Rune Prices Overlay – View rough rune values at a glance
- 📜 Runewords Overlay – Quickly check runewords in-game
- 🧪 Corruptions Overlay – Reference corruption outcomes
- 🧱 Crafting Recipes Overlay – Cube recipes and crafting info
- ⌨️ Global Hotkeys – Toggle overlays instantly
- 🪟 Always-On-Top Overlay – Stays visible over the game
- 🖱️ Draggable Windows – Move overlays anywhere on screen
- ⚡ Lightweight & Fast – Designed to stay out of the way

## 📥 Installation

### Option 1: Installer (Recommended)

1. Download **Pandemonium Overlay Setup.exe** from the Releases page  
   https://github.com/TheHornblow3r/Pandemonium-Overlay/releases
2. Run the installer
3. Launch Pandemonium Overlay from the Start Menu

- Adds Start Menu shortcut  
- Includes uninstall support  

### Option 2: Portable (No Install)

1. Download **Pandemonium Overlay Portable.exe**
2. Place it anywhere (Desktop, tools folder, etc.)
3. Double-click to run

- No installation required  
- Easy to remove

## ⌨️ Hotkeys

All hotkeys work while Path of Diablo is running.

| Overlay | Hotkey |
|------|------|
| Rune Prices | Ctrl + Shift + D |
| Runewords | Ctrl + Shift + R |
| Corruptions | Ctrl + Shift + C |
| Crafting Recipes | Ctrl + Shift + V |
| Breakpoints | Ctrl + Shift + B |
| Hide / Show All | Ctrl + Shift + H |
